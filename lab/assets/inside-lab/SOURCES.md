All result values and flow events are invented for teaching, not copied from patient records or proprietary analyzer software. Tables show selected analytes, not complete CBC/BMP reports. Reference intervals are illustrative adult examples, not universal diagnostic cutoffs. The microcytic pattern does not establish iron deficiency. The hemolysis example does not rule out true hyperkalemia. The flow model uses 200 deterministic events (120 T, 45 B, 35 double-negative); percentages describe that invented set, not expected normal proportions. Double-negative does not establish NK identity. Full panels, controls, gating and clinical context are required in actual practice.
